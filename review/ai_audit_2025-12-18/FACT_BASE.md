# FACT_BASE (Android)

- Baseline commands blocked: `flutter` binary missing in runner; all baseline files show `bash: flutter: command not found` (see baseline_pub_get.txt, baseline_analyze.txt, baseline_tests.txt).
- Background service configured in `lib/services/trackingservice.dart` via `FlutterBackgroundService.configure` with `onStart: _onStart`, `isForegroundMode: true`, `autoStart: false`, channel `geowake_tracking_channel_v2`.
- Ack-based invoke reliability: `_ensureAckListenersRegistered` registers listeners for `registerRouteAck`, `registerRouteDirectionsAck`, `startTrackingAck`, plus streams `activeRouteUpdate`, `routeSwitch`, and `triggerAlarm`; `_invokeWithAckRetry` retries with requestId payloads (trackingservice.dart).
- Background isolate startup `_onStart` registers listeners for `stopService`, `startTracking`, `useInjectedPositions`, `injectPosition`, `foregroundHeartbeat`, `foregroundResumed`, `stopTracking`, `stopAlarm`, `registerRoute`, `registerRouteDirections` before doing other work (trackingservice.dart around _onStart body).
- Heartbeat pause detection: `_startHeartbeatMonitoring` runs in background isolate with 4s timeout; foreground sends heartbeats every second via `_startForegroundHeartbeat`/`_sendHeartbeat` when tracking active (trackingservice.dart).
- Alarm delivery split isolates: background `_checkAndTriggerAlarm` calls `_triggerAlarmNotification`; when `_isBackgroundIsolate` true it invokes `service.invoke('triggerAlarm', {title, body, allowContinue})` for foreground to show notifications; foreground listener in `_ensureAckListenersRegistered` calls `NotificationService().showWakeUpAlarm(...)` (trackingservice.dart).
- Cross-isolate stop/mute requests: NotificationService background callback `notificationTapBackground` writes file flags (`.gw_stop_alarm_flag`, `.gw_end_tracking_flag`, `.gw_mute_journey_flag`) and SharedPreferences backups via `request*ForService`; tracking isolate consumes via `_startAlarmStopPollTimer` polling every 200ms calling `consumeStopAlarmRequest/consumeEndTrackingRequest/consumeMuteJourneyRequest` (notification_service.dart & trackingservice.dart).
- Tracking state persistence: `TrackingStateStore` caches SharedPreferences, reloads in `notificationsMuted` and consume* paths; keys include `_activeKey`, `_pausedKey`, `_snapshotKey`, `_progressPayloadKey`, `_alarmFiredKey` (tracking_state_store.dart).
- Splash restore path: `_checkStateAndNavigate` checks `TrackingStateStore.isAlarmFired()` to cleanup zombie alarms via `TrackingService().completeEndTracking(navigateHome:false)` then routes to `/` or `/mapTracking` based on `isActive` (splash_screen.dart).
- MapTrackingScreen restore: when route args missing, `_restoreState` loads `TrackingStateStore` snapshot; fetches fresh directions if absent and re-saves snapshot; subscribes to `routeSwitchStream` and `activeRouteStateStream` (maptracking.dart).
- Notification actions (foreground) mapped via `classifyAction`: IGNORE→muteJourney/cancelAlarm depending payload, RESUME_TRACKING→resume, END_TRACKING→stopTracking invoke + completeEndTracking, STOP_ALARM→cancelAlarm, DISMISS_ALARM→cancelAlarm (notification_service.dart).
