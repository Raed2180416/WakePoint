# Google Maps Platform pricing as of 2026 (global + India), for GeoWake unit economics

## Summary
As of March 1, 2025, Google Maps Platform replaced the flat $200/month credit with per-SKU monthly free-call allotments: 10,000 free calls/month per Essentials SKU, 5,000 per Pro SKU, 1,000 per Enterprise SKU (Essentials Map Tiles get 100,000), for up to ~$3,250/month of free usage across all products. GeoWake is India-first, and India pricing is substantially lower with LARGER free tiers: 70,000 free/month per Essentials SKU, 35,000 per Pro, 7,000 per Enterprise, and per-1000 rates roughly 60-70% below the global list. The legacy Directions API ($5.00/1k global; $1.50/1k India first paid tier) is now superseded by the Routes API Compute Routes Essentials (same $5.00 global / $1.50 India). For Places, the session-token model means Autocomplete keystrokes are currently FREE when the session ends in a Place Details (New) request — you effectively pay only Place Details Essentials ($5.00/1k global, $1.50/1k India) or Pro ($17.00/1k global, $5.10/1k India). Dynamic Maps (the Maps SDK map-load SKU used by mobile apps) is $7.00/1k global / $2.10/1k India; Static Maps is $2.00/1k global / $0.60/1k India. All prices are USD per 1,000 billable events and were verified against Google's official pricing docs this session (2026-07-18).

## Caveats
- Prices are USD per 1,000 billable events (cost-per-mille). India SKUs are billed in USD on the pricing list but can be paid in INR; the India list is a separate, lower price sheet from the global one.
- GeoWake is India-first: if the Google Cloud billing account qualifies for India pricing (majority of usage + billing in India), use the India numbers, NOT the global list. India free tiers are 7x/7x/7x larger (70K/35K/7K vs 10K/5K/1K) and per-call rates are roughly 60-70% lower — this materially changes unit economics.
- Autocomplete Session Usage being $0 is described by Google as 'currently free' — treat it as a promotional/temporary state that could change; do not model long-term economics assuming free autocomplete sessions are permanent. When a session is abandoned (no terminal Place Details/Address Validation call), the keystrokes bill under the per-request Autocomplete Requests SKU instead.
- The global list shows granular volume bands (0-100K, 100K-500K, 500K-1M, 1M-5M, 5M+); the India list collapses most SKUs to just three bands (free cap, then a flat mid rate to 5M, then a 5M+ discount). Do not assume the India sheet has the same intermediate discount steps as global.
- Free allotments are PER SKU PER MONTH and are consumed first each month before any billing; a mobile app touching several SKUs (Dynamic Maps + Routes + Autocomplete + Place Details + Geocoding) gets each SKU's free block independently.
- Directions API / classic Places API / Distance Matrix API are LEGACY (since 2025-03-01). Build new code on Routes API and Places API (New) — legacy SKUs are excluded from the expanded volume discounts and may be sunset later.
- The Maps SDK for Android map load bills to the Dynamic Maps SKU (one map load per session, per Google's session-based counting for mobile). Confirm exact map-load counting rules for your SDK version before projecting per-user cost.
- SKU IDs (e.g. Autocomplete Requests 4EF4-B17C-B31A) come from the global list; verify the India sheet SKU IDs separately if you need them for billing reconciliation.

## Open questions
- Does GeoWake's Google Cloud billing account actually qualify for India pricing? This must be confirmed in the Cloud Console — it changes every number by ~60-70% and the free tiers by 7x.
- Exact map-load counting for Maps SDK for Android in the version GeoWake ships (per-app-session vs per-map-instance) — needed to convert Dynamic Maps $/1k into $/user/month.
- Whether GeoWake needs Routes Pro (traffic-aware / advanced) or Routes Essentials suffices — the Pro SKU is ~2x the Essentials price and has half the free tier.
- How long the 'Autocomplete Session Usage currently free' promotion lasts — no end date is published; monetization model should stress-test a scenario where it becomes chargeable.
- Whether GeoWake can avoid paid Google APIs entirely for the transit use case (e.g. using cached/offline routing or GTFS data) to keep the per-SKU usage under the India free tiers at low DAU.
